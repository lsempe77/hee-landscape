# 22-cause segmented KLD: global and L&MICs

Standalone adaptation of Fig. 2a using the current 41,610-record eligible master and GBD 2023 DALYs. L&MICs means all low-, lower-middle- and upper-middle-income countries. Both research and DALY distributions change from 2010-2012 to 2021-2023. The latter is the COVID-inclusive extension endpoint, not the earlier 2017-2019 comparison.

L&MICs = low- and middle-income countries (low-, lower-middle- and upper-middle-income groups). 22 GBD level-2 causes; DALY shares p and study-cause-link shares q are separately normalised over this set. KLD = sum p ln(p/q), in nats. Nonnegative disease contributions use p ln(p/q) - p + q; their sum equals KLD. This disease allocation differs from signed p ln(p/q) terms, although the overall total is identical. Level-1 rows sum descendant contributions, retaining within-group mismatch; do not add across sections. Both research and burden change, so the change cannot be attributed solely to research. Intervals: 1,000 study bootstrap draws within year; DALY/coding uncertainty omitted. Zero-count causes receive 0.5 only when needed, following the existing Fig. 2a implementation; details in provenance. Common ordering: level-1 groups, then global DALYs summed over 2010-2023. Panel A includes unknown-country records; Panel B includes mixed-income studies naming an L&MICs setting. Research uses publication-year income; burden uses burden-year income. Latest window includes the COVID period. The 16-cause set excludes mental disorders, all injuries, other infectious and other non-communicable diseases; the 22-cause extension includes them. These are adaptations to economic-evaluation records, not exact replications of the reference sample.

The 16-cause figure follows the existing reference-paper cause set; the 22-cause figure extends it. Both re-normalise shares over their own cause sets, so their totals are not directly interchangeable. A multi-disease record contributes once to each named cause. Level-1 rows are sums of level-2 contributions, not a newly calculated KLD on three collapsed groups. The nonnegative allocation is explicit and is not the signed cause-term allocation used in some KLD displays. Changes can be negative or positive.

CSV values and bootstrap files are in nats. Provenance lists causes, counts, seeds, zero handling and master hash. All hierarchy sums were checked at each endpoint and for each bootstrap draw. Bootstrap intervals condition on fixed DALY estimates. No map files were changed.
