Data Quality Notes

All figures reflect audited, corrected data as of 2026-09-08:

  • ✅ Income classification: World Bank API (fixed 30% Natural Earth error rate)
  • ✅ Population: World Bank 2025 (fixed up to 93% underestimation for fast-growing countries)
  • ✅ CUA/CEA harmonisation: QALY/DALY outcomes → Cost-utility (per extraction rule)
  • ✅ DOI de-duplication: 200 duplicate DOIs removed
  • ⚠️ Geography: Extracted-only for income figures (affiliation proxy is income-biased — see DATA_QUALITY_AUDIT.md)
  • ⚠️ MeSH coverage: 63% C-tree, 57% E-tree, 62% N-tree (harvest 2020–2026 only; 2010–2019 harvest running)

## How to Use This Site

This site presents the **complete figure catalogue** from the Health Economic Evaluation (HEE) evidence mapping project, organized thematically into **six narrative acts** (following the Companion register structure) plus the **Funder Decision Pack**, **Timeline set**, **Map Atlas**, and **Lancet Paper Figures**.

### For Each Figure You Can:

| Action | How |
|--------|-----|
| **Comment** | Highlight any text and click the **hypothes.is** icon (top-right) to annotate |
| **View full-size** | Click any figure to open in lightbox |
| **See the code** | Each figure shows its generating script (`R/fig-*.R`) |
